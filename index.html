Project Modules

Six parts covering the key requirements of the assignment.

Part A – Objects & Classes

Constructors, prototypes, ES6 classes, inheritance and modern JavaScript syntax.

Part B – Array Methods

Map, filter, reduce, forEach, Map, Set, freeze and seal.

Part C – JSON Debugging

JSON serialization, parsing and handling common JSON errors.

Part D – Asynchronous JavaScript

Callbacks, promises, async/await and Promise methods.

Part E – Optimization & Events

Debouncing, throttling, memoization and DOM event handling.

Part F – Integration

Combining JavaScript concepts into an integrated QuickCart application.
